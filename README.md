# Sistemista

Programma per Windows con l'archivio e le statistiche delle estrazioni dei giochi italiani: Lotto, 10eLotto, SuperEnalotto, MillionDay, Win for Life, Eurojackpot, SiVinceTutto, VinciCasa e Simbolotto.

Solo statistiche sulle estrazioni passate: nessuna previsione e nessuna promessa di vincita.

Qui ci sono solo gli installatori, nella sezione **Releases**. Il programma controlla da solo se c'è una versione nuova: Impostazioni, "Controlla aggiornamenti".
