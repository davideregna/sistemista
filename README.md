# Sistemista

Programma per Windows, Mac e Linux con l'archivio e le statistiche delle estrazioni dei giochi italiani: Lotto, 10eLotto, SuperEnalotto, MillionDay, Win for Life, Eurojackpot, SiVinceTutto, VinciCasa e Simbolotto.

Le previsioni hanno sempre l'avviso e la probabilità vera accanto: nessuna promessa di vincita.

Qui ci sono solo gli installatori, nella sezione **Releases**:

- Windows: il file `.exe`
- Mac: il file `.dmg`
- Linux: il file `.AppImage`, oppure il `.deb` per Ubuntu, Debian e Mint

Sul Mac, la prima volta, il programma non si apre da solo: aprite Impostazioni di Sistema, Privacy e sicurezza, e in fondo premete "Apri comunque".

Il programma controlla da solo se c'è una versione nuova: Impostazioni, "Controlla aggiornamenti".
